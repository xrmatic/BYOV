Security

Change Master Password

Your current vault key is re-wrapped with the new password. All encrypted items remain unchanged. You must have the vault unlocked to change the master password.

Argon2id Parameters

These control how much work is done to derive your encryption key. Higher values increase security but make unlocking slower. OWASP recommended values are shown.

Min 64 MiB (65536)

⚠ Changing Argon2id parameters requires re-creating the vault (changing the master password regenerates the key derivation).

Import / Export

Export Encrypted Vault

Download your encrypted vault as a .byov file. The file is completely encrypted with your master password using XChaCha20-Poly1305. Anyone who has this file still needs your master password to decrypt it.

Import Vault from File

Import a previously exported .byov vault file. You will need the original master password that was used when the vault was created or exported.

Device Management

Your device ID is used to track which device last modified each vault item. This enables multi-device sync with last-write-wins conflict resolution.

About BYOV

🔐

BYOV – Bring Your Own Vault

Version 1.0.0

Security Design

  • Zero-knowledge encryption – your master password never leaves your device
  • Argon2id key derivation (64 MiB, 3 iterations, parallelism 4)
  • XChaCha20-Poly1305 authenticated encryption for vault items
  • AES-256-GCM (WebCrypto) for vault key wrapping
  • Two-level key scheme – password change only re-wraps the vault key
  • Random nonces per item, per write
  • Server stores only encrypted blobs – cannot decrypt your data

Storage Providers

  • 🖥 Local Device (offline)
  • 🔥 Firebase Firestore
  • ⚡ Supabase / custom REST API
  • ☁ Microsoft OneDrive
  • 🗂 Google Drive (appDataFolder)
  • 📦 Dropbox

Sync

  • Per-item version sync with last-write-wins
  • Item history / soft-delete tombstones
  • Background sync every 5 minutes

BYOV is open source software provided without warranty. Always maintain a backup of your vault file.
